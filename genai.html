📌 How to use this guide

The 6 must-watch picks (marked ⭐) are the resources that, if you only had limited time, would give you the most per hour invested. Start with Karpathy's Deep Dive (3.5 hrs) and Andrew Ng's Prompt Engineering course (1.5 hrs) — those two alone cover the conceptual and practical foundations that everything else builds on.

DeepLearning.AI has 57+ short courses on GenAI topics — prompt engineering, RAG, agents, LLMOps, fine-tuning, and evaluation — nearly all free and 1–2 hours each. Treat each one as a targeted module you take right before building the corresponding project, not to binge upfront.

Karpathy's Deep Dive is a 3.5 hr general-audience video covering the full training stack — pretraining, supervised fine-tuning, and RLHF — along with practical mental models for hallucinations, tool use, and memory. The closest thing to authoritative ground truth on how LLMs work.

For Phase 3 (your biggest edge as a DevOps engineer), there's a hands-on course that covers containerizing LangChain agents, setting up CI/CD pipelines, and deploying production-grade GenAI systems — skills you already have, applied to AI workloads.

The one paid course worth considering is the Udemy LLM Engineering course by Ed Donner — 20+ models, RAG, QLoRA fine-tuning, agents, HuggingFace, LangChain, and Gradio. Goes on sale for ~$15 regularly. If you want one single structured path, this is it.

🎯 Strategy for mastery
1
Courses are inputs. Projects are outputs. Every week, spend more time building than watching. A half-finished project handling real data is worth more than all courses completed with nothing built.
2
Follow the phase sequence. Phase 1 → Phase 2 → Phase 3. Don't jump to agents before you've built a working RAG system. Each phase's projects create the pain that motivates the next phase's solutions.
3
Your DevOps stack is a superpower. Most GenAI learners struggle with CI/CD, Docker, monitoring, and cost. You already know these — go deeper on the AI-specific parts and skip the ops pain everyone else suffers through.
4
Pair courses with docs. After each short course, read the official docs for the main tool used (Anthropic docs, LangChain docs, HuggingFace docs). Courses teach the concept; docs teach the production API.
5
Journal daily. Write what you built, what confused you, and one question. This is the practice that converts short-term exposure into long-term retention. Don't skip it.
